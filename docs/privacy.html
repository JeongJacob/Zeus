이용약관 개인정보처리방침
01

수집하는 정보

제우스 봇은 서비스 제공을 위해 다음 정보를 수집합니다.

  • 디스코드 사용자 ID (모집 생성 및 참가 처리 목적)
  • 디스코드 서버(길드) ID (서버별 데이터 구분 목적)
  • 디스코드 채널 ID (모집 메시지 관리 목적)
  • 사용자가 직접 입력한 닉네임 및 시작 시간
봇은 이메일, 전화번호, 실명 등 민감한 개인정보를 수집하지 않습니다.
02

정보 이용 목적

수집된 정보는 오직 다음 목적으로만 사용됩니다.

  • 파티 모집 메시지 생성 및 업데이트
  • 참가 신청 및 취소 처리
  • 모집글 자동 삭제 (생성 후 12시간)
03

정보 보관 및 삭제

모집 데이터는 서버별 JSON 파일로 저장되며, 모집 종료(삭제 또는 12시간 경과) 시 자동으로 삭제됩니다. 봇이 서버에서 제거될 경우 해당 서버의 데이터는 더 이상 사용되지 않습니다.

04

제3자 제공

수집된 정보는 어떠한 경우에도 제3자에게 제공, 판매, 공유되지 않습니다.

05

방침 변경

본 방침은 필요에 따라 변경될 수 있으며, 변경 시 본 페이지에 게시됩니다.
