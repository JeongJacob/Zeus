FEATURES

모집의 모든 것을
한 채널에서

복잡한 설정 없이 명령어 하나로 모집글이 생성되고, 버튼으로 모든 걸 처리해요.

🏹

6가지 모드 지원

자유랭크, 일반게임, 내전, 칼바람 나락, 롤체, 솔로랭크 듀오까지 게임 유형별 모집을 모두 지원해요.

🎮

버튼으로 간편 참가

채팅 입력 없이 버튼 클릭 하나로 참가 신청, 예비 등록, 취소까지 가능해요.

⏰

시작 시간 설정

모집자가 직접 게임 시작 시간을 입력해 모집글에 표시할 수 있어요.

🛡️

포지션 선택

자랭·일반게임 모집 시 탑, 정글, 미드, 원딜, 서폿 포지션을 개별 선택할 수 있어요. 정원이 차면 자동으로 비활성화돼요.

👥

인원 자동 관리

참가자 현황이 실시간으로 임베드에 반영되고, 예비 참가자는 순번이 표시돼요.

🎯

솔로랭크 듀오 모집

듀오 파트너를 구할 수 있어요. 참가 시 닉네임, 티어, 선호 포지션을 입력해 매칭 정보를 공유할 수 있어요.

📋

활동 로그 기록

모집 생성 및 삭제 내역을 지정한 채널에 자동으로 기록해요. /로그채널 명령어로 간편하게 설정할 수 있어요.

COMMANDS

명령어 목록

슬래시(/) 명령어로 간단하게 사용할 수 있어요.

/자랭 자유랭크 파티 모집을 시작합니다. 포지션 선택 및 시작 시간 입력이 가능해요.
/일반 롤 일반게임 파티 모집을 시작합니다. 포지션 선택 및 시작 시간 입력이 가능해요.
/내전 10인 내전 모집을 시작합니다. 라인 선택(상관없음 포함) 및 시작 시간 입력이 가능해요.
/칼바람 칼바람 나락 파티 모집을 시작합니다. 5인 슬롯으로 구성되어 있어요.
/롤체 팀파이트 택틱스(롤체) 파티 모집을 시작합니다. 8인 슬롯으로 구성되어 있어요.
/듀오 솔로랭크 듀오 파트너 모집을 시작합니다. 참가 시 닉네임, 티어, 포지션을 입력할 수 있어요.
/로그채널 봇 활동 로그를 기록할 채널을 설정합니다. 관리자 전용 명령어예요.
/지우개 채널의 메시지를 삭제합니다. 1~100개 범위에서 개수를 지정할 수 있어요.
/도움말 사용 가능한 모든 명령어를 안내해드려요.
